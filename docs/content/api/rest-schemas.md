### AuditEntry

One state-changing request, as the daemon recorded it.

Entries never carry request bodies, query strings, headers other than
the user agent, or tool arguments.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `forwarded_for` | string or null | no | What the client claimed through `X-Forwarded-For` or `X-Real-IP`, verbatim and capped at 256 characters. Only as trustworthy as the process that sent it. |

| `method` | string | yes | HTTP method, or `tools/call` for MCP. |
| `path` | string | yes | Request path without its query string, or the MCP mount path. |

| `status` | integer (int32) | yes | Response status. MCP tool calls report 200 for success and the closest HTTP status for a tool error (400, 404, 409, or 500). A request dropped before its response, as when the client disconnects, reports 499. |

| `timestamp` | string | yes | When the request finished, RFC 3339 UTC with milliseconds. |

<div class="schema-anchor" id="NormalizedPosition"></div>

### NormalizedPosition

A position in normalized `[0.0, 1.0]` canvas space.

- `(0.0, 0.0)` = top-left corner of the canvas
- `(1.0, 1.0)` = bottom-right corner of the canvas
- `(0.5, 0.5)` = center of the canvas

Values outside `[0.0, 1.0]` are permitted — they represent positions
beyond the canvas bounds and are handled by [`EdgeBehavior`](@/api/rest-schemas.md#EdgeBehavior).

Used for zone positions and sizes on the canvas, LED positions within
a zone's bounding box, and space regions in multi-room layouts.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `x` | number (float) | yes | Horizontal position. 0.0 = left edge, 1.0 = right edge. |
| `y` | number (float) | yes | Vertical position. 0.0 = top edge, 1.0 = bottom edge. |
